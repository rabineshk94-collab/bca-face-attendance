Major Project Specification

BCA Final-Year Major Project Architecture

System Design, Database Schemas, AI Face Recognition Workflows, and Technical Stack

Technology Stack

  • Web Backend Framework: Python 3.x with Django 5.x MVC
  • Computer Vision Engine: OpenCV (`opencv-python`), NumPy, HOG Feature Extraction
  • Database: SQLite3 Relational Database (`db.sqlite3`)
  • Frontend User Interface: HTML5, CSS3 Glassmorphism Theme, Bootstrap 5, Chart.js
  • Report Engines: ReportLab PDF Generator & CSV/Excel Data Exporter

Database Relational Schema

  • Users: Django Admin superuser table for secure login
  • Departments: Academic departments (`BCA`, `B.Sc CS`, `B.Tech CSE`)
  • Students: Student Profile (`student_id`, `roll_number`, `name`, `department`, `year`, `email`, `phone`)
  • FaceEncodings: 128D facial feature vector JSON storage per student
  • Attendance: Time-stamped daily records with status (`Present`/`Absent`), confidence score %, and method

Anti-Spoofing & AI Verification Features

The system includes Laplacian texture variance analysis to detect photo/screen spoof attempts, multi-angle facial sample vectorization, duplicate check-in prevention for the same day, and a QR code backup attendance fallback.
